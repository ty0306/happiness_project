# World Happiness Report - EDA Dashboard

## Overview
This project is an Exploratory Data Analysis (EDA) dashboard for the World Happiness Report. 
It visualizes the relationship between macro-level metrics (such as GDP per capita) and Happiness Scores. 
This repository serves as a bridge between psychological statistics, well-being research, and data engineering.

## Technologies Used
* **Python**
* **Streamlit** (Frontend Dashboard)
* **Pandas / NumPy** (Data Manipulation)

## How to Run Locally
1. Install the required libraries:
   ```bash
   pip install streamlit pandas numpy
   ```
2. Run the application (Windows):
   ```bash
   python -m streamlit run app.py
   ```
